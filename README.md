# monitoring-cpu-ram
python script for monitoring CPU and RAM using psutil library

🔧 What This Script Does

- Measures current "CPU usage" with interval of 1 second.
- Monitors "RAM usage" in percentage.
- Prints a warning message if:
  - CPU usage > 75%
  - RAM usage > 80%
- then the message will high, healthy or normal according to the system health

---

🧠 Technologies Used

- Python 3
- psutil library
- VS Code on Ubuntu
